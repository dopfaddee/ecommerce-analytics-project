# Project Log

## 07.09.26 — JTBD-гипотезы: почему клиенты возвращаются за повторной покупкой

Сформулировал 3 конкурирующие гипотезы:
1. Доверие к качеству реализации (оформление, товар, доставка)
2. Уникальность / лучшее предложение конкретных товаров
3. Нежелание искать альтернативы (инерция выбора)

Попытался найти способ различить гипотезы через доступные данные (без 
пользовательских интервью, только SQL по своей БД):

- Гипотеза 1 — частично проверяема через долю отменённых/возвращённых заказов.
  Необходимое, но не достаточное условие - низкий процент отмен не доказывает,
  что именно доверие — причина повторных покупок.
- Гипотеза 2 — проверяема через концентрацию повторных покупок на конкретных 
  товарах (сравнение поведения новых и повторных клиентов) — следующий шаг
- Гипотеза 3 — не нашёл способа проверить текущими данными: любой доступный 
  сигнал (частота заказов) оказывается переформулировкой самого явления, 
  а не независимым подтверждением причины. Нужны данные вне текущей схемы — 
  например, источник перехода на сайт или факт сравнения цен

Вывод: продолжаю проверку гипотезы 2 как единственной, для которой есть 
работающий путь через имеющиеся данные.

## 08.09.26 – Проверка Key findings на правдоподобие

При расчёте четырёх ключевых показателей (доля повторных клиентов, концентрация 
выручки на топ-10% клиентов, концентрация на топ-товаре по категориям, доля 
high-value клиентов с риском оттока) сверял каждую цифру с реалистичными 
бенчмарками, а не принимал как готовый вывод.

Результат:
- 2 из 4 показателей *(процент повторных клиентов 97.4%, концентрация на топ-10% клиентов 20.4%)* 
  оказались последствиями способа генерации данных — заказы распределялись между 
  клиентами равномерно случайно, без модели неравномерного поведения (лояльные 
  клиенты vs разовые покупатели). Задокументированы с оговоркой, не используются 
  как основа для гипотез.
- 1 показатель *(концентрация на топ-товаре, 6.6-9.3%)* оказался правдоподобным — 
  риска концентрации не обнаружено, это негативный результат сам по себе 
  (не ведёт к гипотезе).
- 1 показатель *(high-value at risk, 8.5%)* на первый взгляд показался высоким, 
  но при сравнении с ожидаемым значением при случайном совпадении метрик 
  (~12.5%) оказался ниже ожидаемого — то есть не свидетельствует о проблеме.

Вывод: ни один из четырёх находок не тянет на однозначную продуктовую проблему без дополнительного анализа. 
Нужно смотреть глубже, чем агрегированные топ-уровневые цифры — вероятно, в динамике (тренд по месяцам, 
а не статичный срез) или в комбинации метрик, а не в одной отдельной цифре.

## Проверка: тянет ли хоть одна метрика на реальную гипотезу?

Все 4 находки из Key findings не подтвердились как 
самостоятельные продуктовые проблемы — либо послдествие способа генерации данных 
(равномерный random.choice без модели неравномерного поведения), либо 
негативный результат.

Проверил дополнительно: распределение полной RFM-сегментации (champion/loyal/
at_risk/lost). В отличие от предыдущих метрик, здесь есть содержательный сигнал: 
размер сегментов *champion (126)* и *lost (134)* в разы превышает ожидаемый при 
полностью случайном (независимом) распределении R/F/M (~12-13 человек при 
случайности). Причина не в способе генерации, а в том, что количество заказов, 
их давность и сумма трат у клиента реально связаны через логику скрипта 
*(больше заказов → выше шанс недавней покупки → больше потрачено)* — это 
отражает реалистичное поведенческое допущение, а не побочный эффект случайности.

Вывод: *сегмент at_risk (266 клиентов, 33% базы)* — реалистичная отправная точка 
для продуктовой гипотезы: исторически ценные и активные клиенты, показывающие 
признаки снижения активности. 

Беру эту находку как основу для hypotheses.md.
