# E-commerce Product & Analytics Case

Сквозной кейс, демонстрирующий полный цикл продуктовой работы: от построения 
и анализа данных до формулировки продуктовых гипотез, приоритизации инициатив 
и проектирования эксперимента для проверки решения. Разрабатывается как 
портфолио-проект для позиций Product Analyst / Junior Product Manager.

## Зачем этот проект в таком виде

Обычно продуктовые портфолио ограничиваются кейсами в духе 
"как бы я улучшил" в отношении к какой-либо платформе — без реальных данных и без возможности что-либо 
проверить. Этот проект устроен иначе: хоть данные и были сгенерированы с помощью Faker (библиотека для Python), вся продуктовая работа опирается на 
самостоятельно спроектированную базу данных и реальный SQL-анализ, а не на 
гипотетические рассуждения без опоры на цифры.

## Статус проекта

**Завершено:** проектирование БД, генерация синтетических данных, 
SQL-анализ (оконные функции, когортный анализ, RFM-сегментация, оптимизация запросов).
**В процессе:** перевод аналитических находок в продуктовые гипотезы и решения.
**Впереди:** PRD, приоритизация инициатив, дизайн A/B-теста, product sense кейсы, 
финальная сборка сквозного кейса.

## Путь проекта: от данных к продуктовому решению

Готово: 
1. **Данные** — спроектирована и наполнена БД интернет-магазина (5 таблиц, 
   реалистичная схема с constraints, намеренно искажена небольшая часть данных)
2. **Анализ** — решено  14 аналитических задач, сформулированных в формате реальных бизнес-запросов. Используя SQL, 
   найдены содержательные паттерны: сегментация клиентов по RFM, 
   соотношение новых/повторных заказов, концентрация выручки в топ-товарах, 
   клиенты с высоким Recency-риском оттока

В процессе:
3. **Гипотезы** — аналитические находки переведены в продуктовые проблемы
4. **Решение** — для приоритетной проблемы разработан PRD с чёткими метриками 
   успеха и user flow
5. **Проверка** — спроектирован A/B-тест для проверки решения, включая разбор 
   гипотетических неоднозначных результатов и решения на их основе

## Инструменты

PostgreSQL, pgAdmin, Python (pandas — в процессе освоения), Excalidraw/Miro 
(диаграммы), статистика для A/B-тестирования (scipy/statsmodels — планируется)
